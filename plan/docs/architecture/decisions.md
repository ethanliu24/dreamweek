# Design decisions and repository audit

## Starting point · 24 November 2026

On branch `main`, the tracked project contains `index.html`, npm manifests, two public SVGs and ignore rules. Root AGENTS.md and the plans tree were present as untracked user work. The HTML mounts #app and imports /src/main.js. The src directory is empty. No game systems, production audio, test script, Pages workflow, Vite config or configured Git remote were found. The local environment runs Node 24.16.0. package.json declares native ES modules, Three.js ^0.187.0 and Vite ^8.3.6. The lockfile resolves 0.187.0 and 8.3.8. Scripts are dev, build and preview. The baseline build fails resolving /src/main.js. Foundation supplies that file during implementation.

## Which direction to build

Read the row for the assigned feature alongside its world source. The first two choices were confirmed by the author. The other rows are planning resolutions based on the cited drafts.

| Topic and source discrepancy | Implementation direction and reason |
|---|---|
| Fire gameplay specified carrying and free descent. Earlier Fire story and character drafts described steering a gondola. | Climb to Wick, press E, carry him the entire way down. Jump between lanterns or drop directly. Keep his rising lantern, seagull, frightened reaction and relief dialogue. Trigger the descent line on pickup and resolution on contact with festival ground. |
| The earlier Earth gameplay draft moved firing to the hub. Earth story, dialogue and hub progression require a finished pot. | Carry Bob to the wheel, shape him, use Candle there, then collect a fired empty pot. The hub hearth first receives the filled pot after Water. |
| Overview uses bed, fade and sometimes immediate return. Hub gameplay specifies a hammock and active return point. | Sleep in the outdoor hammock. For the five ordinary dreams, earning the reward enables E at the yellow spawn ring. Stay and explore until then. Use the same circular black iris in both directions. Void has an explicit capture exit. |
| Overview mentions multiple waves of mini frogs and escaping to another encounter. Void specifies cubes and one arena. | Seven weekdays occupy six dream environments. Sunday has one cube wave, then the Sun pickup. Monday begins as the Wizard steps forward on that arena. E on his unconscious body after the Moon pickup returns both to the hub. |
| Wood's character and scenery mention cooking and ingredient shelves. Its dialogue notes only Firewood. Gameplay, story and overview specify a short ignition and two rewards. | Retain the shy cook and any decorative shelves. Talk, light prepared logs with Candle, talk for Firewood **and** Healing Mushroom. Retain its healing identity as an item. Void grants invincibility and has no HP use for it. |
| Player sheet describes three configurable slots. Permanent items, abilities and both essences can exceed three. | Use three visible inventory cells per page, with automatic inventory storage and paging. Keep abilities separate. This retains the three-cell layout and permits all mandatory pickups. No capacity puzzle is specified. |
| Teal wears/blows a whistle but the player finds his missing whistle underwater. | Use the shell siren at lockdown. Teal reaches for an empty lanyard. Show the single identifiable whistle in coral and in the evidence presentation. Keep the dialogue text. |
| Water story stops during the missing whistle scene. Metal gameplay ends mid-sentence. Metal story mentions a spoken soup exchange absent from its dialogue. Earth story names a separate monologue ID absent from its dialogue. | Use Water gameplay plus dialogue for the whistle denial, jellyfish witness, choices and confession. Use the complete Metal puzzle rules above the cut and the story for the reward beat. Convey stirring with a gesture. Earth thoughts are part of EARTH_INTRO. Preserve supplied lines. |
| Whole-game target is 30–40 minutes, each dream ≤5 minutes, with much shorter local targets. | Time a first playthrough including hub and dialogue, then report active play, reading and optional wandering separately. Preserve the short mechanics. A duration shortfall is a creative review item, not a reason to add grind. |
| Shield and mushroom imply damage, but Void explicitly grants invincibility. Player controls omit the ultimate key. | Shield absorbs the first incoming contact including knockback and recharges after 3 s. Later contacts produce modest knockback only. Keep Mushroom in inventory. Use Q with a visible prompt for the manually activated finisher. |
| Intro and ending specify one image each. Overview describes a sequence of story events. | Keep each image steady through the authored lines. Use two original compositions, with the BFCM washing-machine aside on arrival and no playable epilogue. |

The December 8 assignment requires at least five original field recordings. The game can be developed with cue fallbacks before delivery. Final audio and publishing require the author's original takes and an actual Pages destination. A performance or calendar-driven change to a required mechanic should return to the author for a design decision.
