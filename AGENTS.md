# AGENTS.md — Dreamweek

## Project

Dreamweek is a single-player browser-based 3D game built with Three.js, WebGL and deployed through GitHub Pages.

## Instructions

- Do not commit any code.
- Don't write test cases.
- Before implementing a task, inspect the relevant existing code and planning documents.
- Start at [the implementation roadmap](plan/docs/implementation.md). Read the assigned task, its linked contracts and any applicable [design decisions](plan/docs/architecture/decisions.md).
- Use [visual design](plan/docs/visual-design.md) and the relevant sources in `plan/game/worlds/` for visual work.
- Treat established planning decisions as requirements. Do not silently change mechanics, designs, or progression.
- Keep modules focused, modular, and easy to extend. Avoid unnecessary abstractions and dependencies.
- Keep individual worlds independent. Reuse shared systems only where appropriate.
- Use Three.js procedural geometry and code-based animation by default. Do not introduce a Blender workflow.
- Keep implementations within the documented scope. Avoid unrelated refactoring.
- Preserve existing user changes.
- Run relevant builds and tests after implementation. Inspect rendered results for visual tasks.
- Use the human acceptance walkthrough at each milestone. Report changed files, verification performed, and remaining issues.

Read only the documentation relevant to the assigned task. Do not unnecessarily load every world document or duplicate planning information.
